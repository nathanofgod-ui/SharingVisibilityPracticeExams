# Sharing and Visibility Practice Exams

A set of practice questions to train for the **Salesforce Certified Sharing and Visibility Architect** exam, built with HTML, CSS and JavaScript.

## Topics covered

- Organization-wide defaults (OWD)
- Role hierarchy
- Sharing rules
- Manual and Apex managed sharing
- Teams (account, opportunity, case)
- Territory management
- Profiles, permission sets and field-level security
- Large data volumes and sharing performance
